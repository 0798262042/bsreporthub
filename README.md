#  Attendra System

**Attendra** is a modern web-based attendance management system developed for the **Nelson Mandela University (NMU) Business School**.

While working at the NMU Business School as a Lecture Assistance technician, 
I noticed that attendance reports generated by platforms such as **Zoom** and **Microsoft Teams** were not well organized and 
required significant manual effort to clean and analyze. This inspired me to develop **Attendra**—a solution that transforms 
raw attendance spreadsheets into accurate, professional reports.

The system automatically cleans attendance data, merges duplicate records, organizes student information, generates meaningful attendance 
insights, and allows staff to view and export professional reports in **PDF** and **Excel** formats. 
It provides NMU staff with a faster and more efficient way to monitor students attending online classes on a daily basis.

## Features

-  Upload Excel attendance spreadsheets
-  Automatic data cleaning and duplicate merging
-  Attendance insights and analytics
-  Professional attendance reports
-  Export reports to PDF and Excel
-  Shared report repository for all authorized users
-  Secure authentication with Admin and User(staff memebers) roles
-  Modern, responsive user interface

##  Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase
